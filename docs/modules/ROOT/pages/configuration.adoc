= Configuration

Configuration is loaded by `onecx_pipecat.config.Settings`, a
`pydantic-settings` model with the environment prefix `ONECX_`.
Nested fields use `__` as the delimiter, so:

[source,shell]
----
ONECX_PORT=9000
ONECX_AUTH__ISSUER=https://issuer.example
ONECX_SPEECH__STT_PROVIDER=aws
ONECX_PERMISSION__VOICE_RESOURCE=VOICE
----

== Reference

[cols="25,20,55",options="header"]
|===
| Field | Default | Description

| `app_name`
| `onecx-pipecat`
| Display name of the application.

| `host`
| `127.0.0.1`
| Bind address for the HTTP server.

| `port`
| `8080`
| Port for the HTTP server.

| `log_level`
| `INFO`
| Application log level.

| `default_tenant_id`
| `local`
| Tenant identifier used when a request does not carry one.

| `auth.issuer`
| `https://auth.example`
| Expected JWT issuer, validated by `JwtAuthAdapter` when verifying the
`apm_principal_token` carried in `start_session`.

| `auth.audience`
| `onecx-pipecat`
| Expected JWT audience, validated by `JwtAuthAdapter`.

| `auth.token_claim_subject`
| `sub`
| JWT claim name read as the authenticated subject.

| `auth.jwks`
| (empty)
| Keycloak JWKS used to verify the `apm_principal_token` carried in
`start_session`: an embedded `keys` document as a JSON string, or a URL.
Empty fetches `{auth.issuer}/protocol/openid-connect/certs`. The set is
refetched when a token carries an unknown `kid` (at most once a minute).

| `auth.client_id`
| `onecx-pipecat`
| Client identifier of Pipecat's own OIDC client-credentials grant; the
resulting token is sent as `Authorization: Bearer` to ai-provider, chat, and
permission services (never to MCP servers).

| `auth.client_secret`
| (empty)
| Client secret for Pipecat's OIDC client-credentials grant.

| `auth.token_endpoint`
| (empty)
| OIDC token endpoint for the client-credentials grant. Empty uses
`{auth.issuer}/protocol/openid-connect/token`.

| `agent_config.default_agent_id`
| `onecx-agent`
| Default agent to pin when no override is present.

| `agent_config.default_snapshot_version`
| `1`
| Default snapshot version to pin.

| `agent_config.base_url`
| `http://onecx-ai-provider-svc:8080`
| Base URL of onecx-ai-provider-svc; `HttpAgentConfigAdapter` calls
`GET /v1/agents/{id}/configuration` once per session.

| `chat.base_url`
| `http://onecx-chat-svc:8080`
| Base URL of onecx-chat-svc; `HttpChatAdapter` calls
`GET /internal/chats/{id}` to load the chat as the user.

| `speech.stt_provider`
| `inmemory`
| STT provider identifier.

| `speech.tts_provider`
| `inmemory`
| TTS provider identifier.

| `speech.sample_rate_hz`
| `16000`
| Expected audio sample rate in hertz.

| `persistence.backend`
| `inmemory`
| Persistence backend identifier.

| `persistence.max_entries_per_session`
| `512`
| Soft cap on entries kept per session.

| `permission.base_url`
| `http://onecx-permission-svc:8080`
| Base URL of onecx-permission-svc; `HttpPermissionAdapter` calls
`POST /v1/permissions/user/{productName}/{appId}` to check the user's voice
permission.

| `permission.voice_product_name`
| `onecx-ai`
| `productName` of the application that owns the voice permission.

| `permission.voice_app_id`
| `onecx-ai-ui`
| `appId` of the application that owns the voice permission.

| `permission.voice_resource`
| `VOICE`
| `resource` of the OneCX permission that grants voice.

| `permission.voice_action`
| `USE`
| `action` of the OneCX permission that grants voice.

| `mcp.timeout_seconds`
| `30.0`
| HTTP timeout for MCP calls. MCP server URLs are *not* configured here: they
come from each agent's configuration (`mcpServers[].url`).

|===

== Real and in-memory adapters

The OneCX boundaries — authentication, agent configuration, chat, permission,
and MCP — always use their real adapter (`JwtAuthAdapter`,
`HttpAgentConfigAdapter`, `HttpChatAdapter`, `HttpPermissionAdapter`,
`HttpMcpAdapter`). There is no in-memory fallback a deployment could silently
run on: a token that cannot be verified against the issuer's JWKS, or a
service call whose client-credentials token cannot be obtained, fails closed.

Speech and persistence still use in-memory adapters because no real ones
exist yet; `persistence.max_entries_per_session` is enforced by
`InMemoryPersistence`, and `speech.*` is loaded but not yet read.

Not yet read by any adapter: `agent_config.default_agent_id`,
`agent_config.default_snapshot_version`, and `persistence.backend`.

== Precedence

Explicit constructor kwargs > environment variables > the defaults
declared on the model. `pydantic-settings` handles this precedence for you.
