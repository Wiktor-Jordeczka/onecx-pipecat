= Configuration

Configuration is loaded by `onecx_pipecat.config.Settings`, a
`pydantic-settings` model with the environment prefix `ONECX_`.
Nested fields use `__` as the delimiter, so:

[source,shell]
----
ONECX_PORT=9000
ONECX_AUTH__ISSUER=https://issuer.example
ONECX_SPEECH__STT_PROVIDER=aws
ONECX_PERMISSION__DEFAULT_ACTION=deny
----

== Reference

[cols="25,20,55",options="header"]
|===
| Field | Default | Description

| `app_name`
| `onecx-pipecat`
| Display name of the application.

| `host`
| `127.0.0.1`
| Bind address for the HTTP server.

| `port`
| `8080`
| Port for the HTTP server.

| `log_level`
| `INFO`
| Application log level.

| `default_tenant_id`
| `local`
| Tenant identifier used when a request does not carry one.

| `auth.issuer`
| `https://auth.example`
| Expected JWT issuer, validated by `JwtAuthAdapter` when verifying the
`apm_principal_token` carried in `start_session`.

| `auth.audience`
| `onecx-pipecat`
| Expected JWT audience, validated by `JwtAuthAdapter`.

| `auth.token_claim_subject`
| `sub`
| JWT claim name read as the authenticated subject.

| `auth.jwks`
| (empty)
| Keycloak JWKS used to verify the `apm_principal_token` carried in
`start_session` — either the embedded `keys` document as a JSON string or a
URL the JWT adapter fetches once.

| `auth.client_id`
| `onecx-pipecat`
| Client identifier of Pipecat's own OIDC client-credentials grant, used to
obtain a service token for outbound calls to OneCX services.

| `auth.client_secret`
| (empty)
| Client secret for Pipecat's OIDC client-credentials grant.

| `auth.token_endpoint`
| `https://auth.example/protocol/openid-connect/token`
| OIDC token endpoint Pipecat exchanges its client credentials against.

| `auth.backend`
| `inmemory`
| Which auth adapter `build_auth` builds: `inmemory` (`InMemoryAuthAdapter`)
or `jwt` (`JwtAuthAdapter`, verifies the `apm_principal_token` against
`auth.jwks`). Selecting the real adapter is a configuration change, not a code
change.

| `agent_config.default_agent_id`
| `onecx-agent`
| Default agent to pin when no override is present.

| `agent_config.default_snapshot_version`
| `1`
| Default snapshot version to pin.

| `agent_config.base_url`
| `https://agentsvc.example`
| Base URL of the service exposing
`GET /v1/agents/{agent_id}/configuration`, pinned once per session.

| `agent_config.backend`
| `inmemory`
| Which agent-configuration adapter `build_agent_config` builds: `inmemory`
(`InMemoryAgentConfigAdapter`) or `http` (`HttpAgentConfigAdapter`). Selecting
the real adapter is a configuration change, not a code change.

| `chat.base_url`
| `https://chat.example`
| Base URL of onecx-chat-svc, used to load a chat by id as the user.

| `chat.backend`
| `inmemory`
| Which chat adapter `build_chat` builds: `inmemory` (`InMemoryChatAdapter`)
or `http` (`HttpChatAdapter`). Selecting the real adapter is a configuration
change, not a code change.

| `speech.stt_provider`
| `inmemory`
| STT provider identifier.

| `speech.tts_provider`
| `inmemory`
| TTS provider identifier.

| `speech.sample_rate_hz`
| `16000`
| Expected audio sample rate in hertz.

| `persistence.backend`
| `inmemory`
| Persistence backend identifier.

| `persistence.max_entries_per_session`
| `512`
| Soft cap on entries kept per session.

| `permission.default_action`
| `always_ask`
| Default `PermissionAction` for tools that do not match a policy.

| `permission.base_url`
| `https://permissions.example`
| Base URL of onecx-permission-svc, used to check the user's existing voice
permission through the existing permission interface.

| `mcp.default_server_name`
| `inmemory`
| MCP server identifier (in-memory by default).

| `mcp.servers`
| `{"inmemory": "inmemory"}`
| Map of MCP server name to endpoint. Non-HTTP endpoints (for example the
in-memory one) are skipped by `HttpMcpAdapter` during the once-per-session
tool discovery; a server whose `tools/list` call fails is reported through a
`degraded_capability` event.

| `mcp.timeout_seconds`
| `30.0`
| Per-invocation MCP timeout.

| `mcp.backend`
| `inmemory`
| Which MCP adapter `build_mcp` builds: `inmemory` (`InMemoryMcpAdapter`) or
`http` (`HttpMcpAdapter`). Selecting the real adapter is a configuration
change, not a code change.

|===

== In-memory adapter coverage

The in-memory adapters are settings-light stand-ins: each one loads and
validates its nested `Settings` model, but only some fields are read at
runtime. This section states exactly which, so the reference above matches
shipped behavior.

* *Read by the in-memory adapters today:*
  ** `permission.default_action` — the fallback `PermissionAction` that
     `InMemoryPermissionAdapter` returns for tools that match no explicit
     (write) policy.
  ** `persistence.max_entries_per_session` — the per-session cap that
     `InMemoryPersistence` enforces by evicting the oldest entry when a
     session exceeds it.
* *Read by the HTTP / JWT adapters:*
  ** `auth.issuer`, `auth.audience`, and `auth.token_claim_subject` — the
     claim fields `JwtAuthAdapter` validates when it verifies the
     `apm_principal_token` carried in `start_session` against `auth.jwks`
     (signature, issuer, and expiry).
  ** `agent_config.base_url` — the base URL `HttpAgentConfigAdapter` calls
     (`GET /v1/agents/{agent_id}/configuration`) to pin the agent
     configuration once per session.
  ** `chat.base_url` — the base URL `HttpChatAdapter` calls to load a chat by
     id as the user.

  The in-memory auth stand-in (`InMemoryAuthAdapter`) resolves tokens from a
  local table rather than parsing JWTs, so it does not read `auth.jwks`,
  `auth.issuer`, `auth.audience`, or `auth.token_claim_subject`.

* *Read by the factory to pick an adapter implementation:*
  ** `auth.backend`, `agent_config.backend`, `chat.backend`, and
     `mcp.backend` — the selectors `build_auth`, `build_agent_config`,
     `build_chat`, and `build_mcp` use to return the in-memory stand-in or the
     real adapter. Setting `auth.backend` to `jwt` or any other backend to
     `http` is how a deployment switches a capability to its real adapter
     without a code change.
* *Loaded and validated, but not yet read by the shipped adapters:*
  `speech.*` (the speech-backend knobs), `agent_config.default_agent_id` and
  `agent_config.default_snapshot_version` (the default pin),
  `persistence.backend` (the backend selector), the `mcp.servers` selector and
  `mcp.timeout_seconds` (the per-invocation timeout), `permission.base_url`
  (the base URL a real permission adapter would call to check the user's voice
  permission — the in-memory permission adapter resolves that in-process), and
  the `auth.client_id` / `auth.client_secret` / `auth.token_endpoint` OIDC
  knobs (used only when a real auth adapter must obtain its own service token).
  These fields are placeholders reserved for real adapter implementations, not
  consumed by the shipped in-memory / HTTP ones.

== Precedence

Explicit constructor kwargs > environment variables > the defaults
declared on the model. `pydantic-settings` handles this precedence for you.
